# Historical upstream changesets

These files preserve Matt Pocock's original MIT-licensed changesets and attribution exactly as inherited from the upstream `mattpocock/skills` repository. They describe the original `mattpocock-skills` package; they are reference material, not pending QuickStark releases.

Keep active QuickStark release changesets in the repository's `.changeset/` directory, targeting the `qs-skills` package. Changesets does not apply the historical files in this documentation archive.
